# v0.14.1 - Publication and Validation Repair

This patch release repairs the GitHub Pages publication contract and removes the network dependency from candidate schema validation.

## Changes

- converted documentation links to Jekyll-resolved links so generated HTML does not retain `.md` targets that 404;
- defined the Pages publication surface as root `index.md` plus `docs/**/*.md` and excluded repository/source Markdown from deployment;
- strengthened generated-site verification to detect missing HTML, raw Markdown endpoints, unresolved `.md` links, and unstyled pages;
- replaced Ajv with a repository-local validator implementing the JSON Schema features actually used by TIS;
- removed `npm ci` from candidate CI and removed all npm development dependencies;
- established a repository scope/admission policy separating TIS Core from ecosystem adapters and repository assurance evidence.

No canonical trust-artifact schema contract is intentionally changed by this patch release.
