# v0.13.0 - Semantic Traceability and Portfolio Contracts

TIS v0.13.0 makes the repository's normative dependency on the Trust Systems Meta Model (TSMM) machine-verifiable while preserving TIS authority over schema identifiers, serialization, validation contracts, and releases.

## Highlights

- stable TSMM semantic references on canonical TIS artifact schemas;
- machine-readable TSMM semantic coverage and artifact mapping;
- portable portfolio relationship, repository authority, adoption-path, and validation-result contracts;
- compatibility and local relationship declarations for the TSMM/TIS boundary;
- semantic-alignment, authority-transfer, mapped-artifact, and version-drift validation;
- generated portfolio alignment evidence under `artifacts/portfolio/`;
- task-oriented GitHub Pages information architecture and a machine-checked navigation contract;
- reduced CI dependency surface by removing the unused npm Mermaid runtime dependency.

## Compatibility posture

The release is additive for existing portable artifact contracts. TSMM remains authoritative for canonical semantic meaning. TIS remains authoritative for machine-readable contract design and validation behavior.

## Validation

```bash
npm ci --no-audit --no-fund
npm run candidate:check
```

The candidate gate now includes schema validation, governance, portfolio relationships, TSMM semantic alignment, version consistency, documentation checks, GitHub Pages IA checks, Mermaid checks, and evidence generation.
